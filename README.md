WaveRace65:

This intends to be a spiritual successor to Waverace

Aims for project:
- Work on Windows, Linux, Maybe Mac OS, Wii U, 3DS, and web browser
- runs well hopefully and has very low requirements
- Cross platform Online play with P2P connection.

Progress:
- Camera fixed to object, currently Tuna, WILL BE CHANGED
- Model loading (.obj only which is fine)
- Easy to use Struct for model loading.
- Easy to use function for creating and translating object.
- MacOS support complete (as long as you have opengl)
